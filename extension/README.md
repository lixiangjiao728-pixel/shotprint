# 镜谱取证桥 v0.7.1

这是 Shotprint 的 Manifest V3 未打包扩展，技术版本和用户可见版本均为 0.7.1；支持采集原视频作品指纹、三平台匿名评论、抖音滚轮式推进和跨屏累计，并在扩展重载导致桥接上下文失效时立即给出刷新提示。

## 安装

1. 在 Chrome/Edge 地址栏打开 chrome://extensions 或 edge://extensions。
2. 开启“开发者模式”，点击“加载已解压的扩展”，选择本目录（或解压后的 ZIP 目录）。
3. 打开扩展详情，把“网站访问权限”设为“在所有请求的网站上”。权限仅覆盖镜谱站点、抖音、B 站、小红书和短链接跳转域名。
4. 回到镜谱网页并刷新一次。首页“扩展自检”应显示 0.7.1 和主采集通道可用；联网区会独立显示百炼已配置、未配置或鉴权失败，不能用扩展状态替代搜索实测。

## 采集行为

- 只有用户点击镜谱的“开始采集与分析”后，后台才打开原视频页并注入 collector.js。
- 注入后先进行版本握手，再读取当前页面已加载的评论；每次最多 200 条、90 秒、15 次有界滚动。
- 页面适配器失败时，扩展可代理访问仅监听127.0.0.1的伴侣；伴侣只接受三平台URL和固定动作，配对令牌只保留在扩展内存30分钟。
- 只回传正文、点赞数、粗粒度时间和父子关系；用户名、头像、用户 ID、Cookie 和账号凭证永不回传。
- 遇到验证码、登录墙、403、429 或页面结构变化立即停止，不绕过平台风控，并显示结构化错误码。
- 原视频页关闭、权限不足、旧版本、握手超时和重复点击都会明确结束当前任务，不会无限停在“识别中”。

## 更新和恢复

修改扩展代码后，在扩展管理页点击“重新加载”，然后只需刷新镜谱网页；下一次采集会自动打开并注入新脚本。

如果首页显示“桥接未连接”或“版本过旧”：

1. 删除/停用其他旧版镜谱扩展，避免多个后台同时响应。
2. 重新加载本目录，确认无红色错误。
3. 检查网站访问权限并刷新镜谱网页。
4. 使用首页“复制安全诊断信息”，其中不含评论、Cookie 或账号内容。

遇到验证码、403 或 429，请先在原平台处理，也可使用手动评论入口。伴侣只读取页面已经收到的评论响应，不重放带签名URL。三平台成功链路仍需在登录浏览器逐条验证，详见 `docs/video-analysis.md`。

## 视频读取

确认同一作品后，media.js 仅在用户已授权分析的任务中读取可访问 MP4；媒体地址与登录凭据不离开平台标签页。分块传输上限 300MB，最长 300 秒，主站再验证音视频轨与实际时长。blob、分离音视频或访问失败保留评论，提供用户确认的录制/原片上传入口。协议与内存有效期以 `docs/video-analysis.md` 为准。

发布前运行 `tools/package-extension.ps1`，同时更新 ZIP、base64 与 SHA256；修改扩展脚本必须提升版本并重新加载扩展，不只刷新网站。
